# Beta Stronghold Finder
A program to find the 3 strongholds in your beta 1.9 world.

# Usage
- Run this tool with `java -jar "beta-stronghold-finder.jar"` in your terminal.
- Paste in your world seed. (This can be found by opening your level.dat in NBTEditor or [here](https://irath96.github.io/webNBT/))
